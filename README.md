SkyForge is a 2D flight combat game that runs fully offline in a desktop browser — plain
ES modules on a canvas, no libraries, no network. Fly a real-feeling flight model (lift,
drag, induced drag, stall envelope, G-limits, turbulence) through 8 missions: ring chains,
canyon races, heavy cargo hauls, storm intercepts and night ops against dogfighting AI
bandits that pursue, attack and evade with guns, heat-seeking missiles and flares. Earn
credits and XP, climb 10 pilot ranks, buy 8 airframes, fit a 15-part tech tree across
wings / engine / armor / avionics slots, paint your plane with unlockable liveries, chase
10 medals, and land on the runway to bank the sortie. Storm cells drive wind shear,
turbulence and lightning; free flight runs a full day/night cycle.

## Run it

```sh
node serve.ts        # serves game/ on http://localhost:8080
# then open http://localhost:8080 in a desktop browser
```

Controls: WASD / arrows pitch & roll, Q/E yaw, Shift/Ctrl throttle, F guns, R missile,
X flares, V camera, L end sortie, Esc menu. H hangar, P livery shop, M missions.
